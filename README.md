# Marjorie Boutique

## Design System
### 60-30-10 Color Palette
*   **60% Dominant (Base):** `#FAFAFA` (Light) / `#1C1917` (Dark Mode)
*   **30% Secondary (Text/Borders):** `#1C1917` (Light) / `#FAFAFA` (Dark Mode)
*   **10% Accent (Buttons/Highlights):** `#E11D48` (Rose Red)

### Visual Style
**Minimalism** - The design utilizes ample negative space, sharp borders, and a clean typography scale to create a high-end, editorial feel suited for a boutique.

### Contrast Check
*   **Light Mode:** Text `#1C1917` on background `#FAFAFA` yields a contrast ratio of **15.8:1** (Passes WCAG AAA).
*   **Dark Mode:** Text `#FAFAFA` on background `#1C1917` yields a contrast ratio of **15.8:1** (Passes WCAG AAA).

## Features
*   Semantic HTML structure & Responsive Tailwind CSS layout.
*   Dark mode toggle with `localStorage` support.
*   GSAP Page-Load Intro Timeline with Stagger and Replay Button.
*   ScrollTrigger section reveals and a scrub-linked progress bar.
*   Reduced-motion accessibility support.
